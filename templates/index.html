Capabilities

Everything You Need for Image Forensics

A complete suite of metadata tools designed for privacy-conscious users, security researchers, and digital forensics professionals.

Deep Metadata Analysis

Extract EXIF, IPTC, XMP, ICC Profile, GPS coordinates, camera settings, and over 50 metadata fields from any image.

Metadata Cleaner

Selectively remove GPS, EXIF, IPTC, comments, thumbnails, or wipe all metadata at once. Download the clean image instantly.

Metadata Editor

Edit Author, Copyright, Description, Software, Keywords, Title, and more. Save changes and download the modified image.

Side-by-Side Compare

Upload two images and compare their metadata with color-coded diff highlighting. Spot changes, additions and removals instantly.

GPS Map Viewer

Automatically detect GPS coordinates and display photo location on an interactive Leaflet.js map with a direct Google Maps link.

Multi-Format Export

Export metadata as JSON, CSV, TXT or a professionally styled PDF report. Batch-clean multiple images and download as a ZIP archive.

Image Histogram

Visualize RGB channel distribution with interactive Chart.js histograms. Detect image manipulation through anomalous patterns.

Color Palette

Extract the dominant color palette from any image using median-cut quantization. Click any swatch to copy the hex code.

History & Analytics

Every operation is logged in SQLite. Browse history, search by filename, view analytics charts for operations and file formats.

Workflow

How It Works

1. Upload

Drag & drop or browse to select your image (JPG, PNG, TIFF, WEBP). Multiple files supported for batch processing.

2. Analyze

Instantly view all metadata: EXIF camera data, GPS location, software info, timestamps, and raw EXIF values.

3. Act & Export

Edit fields, strip metadata, export as PDF/JSON/CSV, or compare two images. Download the processed result in seconds.
